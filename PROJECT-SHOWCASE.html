02 / Approach

Designed around a simple customer journey.

The booking interface breaks the request into clear steps, while a separate owner view supports managing incoming requests.

01

Choose a service

Customers browse beauty services and see the listed price before they start a request.

02

Pick a time

A date and time-slot selection makes the preferred appointment time part of the request.

03

Send the request

Customers add contact details and notes. The UI makes clear that a request is not yet a confirmed appointment.

04

Manage as the owner

An owner sign-in and dashboard provide a place to review requests and handle appointments.

03 / Stack

Lightweight frontend. Firebase services.

A compact, installable web app built with browser standards and Firebase's client SDK.

01 / UIHTML5

Semantic document structure for the booking and owner views.

02 / StylingCSS3

Responsive styling with mobile-first layouts and web app theming.

03 / LogicJavaScript ES modules

Interactive service, time-slot, request, and dashboard flows.

04 / PlatformFirebase

Firebase Authentication, Cloud Firestore, and Firebase Hosting.

05 / InstallProgressive Web App

Web app manifest, standalone display, and service worker.

06 / SDKFirebase JS SDK 12.1

Modular Firebase browser SDK loaded as ES modules.

07 / SourceGit + GitHub

Project source and version history in a public repository.

08 / DeliveryHTTPS hosting

Deployed to Firebase Hosting at the live project URL.

Current deployment note. The live interface loads, but Firestore currently denies client access under its production rules. Real booking reads and writes require carefully scoped Firebase Security Rules before customer bookings are enabled. No private service-account credentials belong in the browser app or public repository.
